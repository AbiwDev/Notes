# Notes

A notes management web application built with Python and Django.

## 🛠️ Technologies

* Python
* Django
* SQLite
* HTML
* CSS

## ✨ Features

* Create notes
* View notes
* Update notes
* Delete notes
* Database integration
* Django templates

## 🎯 Project Goal

This project was created to practice Django fundamentals, database operations, CRUD functionality, and building web applications.

## 🚀 Getting Started

### 1. Clone the repository

```bash
git clone https://github.com/AbiwDev/Notes.git
cd Notes
```

### 2. Create a virtual environment

```bash
python -m venv .venv
```

### 3. Activate the virtual environment

Windows:

```bash
.venv\Scripts\activate
```

### 4. Install Django

```bash
pip install django
```

### 5. Apply migrations

```bash
python manage.py migrate
```

### 6. Run the server

```bash
python manage.py runserver
```

The application will be available at:

```text
http://127.0.0.1:8000/
```
